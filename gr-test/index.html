How it works
Create a game, others join from this list. A game starts when it's full (2/2, 3/3…) — it won't start short. The host can end the game at any time: it disappears from the list and everyone goes back here. When a game finishes, everyone picks rematch or end — a rematch only happens if all players choose it. Games idle for 5 minutes time out and vanish.
